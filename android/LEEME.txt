LEEME - App Android del beacon
==============================

App del telefono (spec 04/06 de Tarea 2). Ya es un proyecto de
Android Studio AUTOCONTENIDO: incluye app/src/main/java/logicaFakeTelefono/
(la logica de la spec 04). No hay que copiar nada de fuera.

1) ABRIR EN ANDROID STUDIO
   - Android Studio -> File -> Open -> seleccionar esta carpeta (android/)
   - Aceptar "Trust Project" y esperar al primer Sync (la primera
     vez descarga Gradle 8.7, el plugin AGP 8.5.2 y appcompat).
   - Si pide instalar SDK/aceptar licencias, aceptar.

2) URL DEL SERVIDOR (MainActivity.URL_SERVIDOR)
   - Emulador: http://10.0.2.2:8080/rest/guardarCodigo.php  (por defecto)
   - Movil fisico: la IP del PC en la misma red, por ejemplo
     http://192.168.1.50:8080/rest/guardarCodigo.php

3) ARRANCAR EL SERVIDOR EN EL PC (desde la carpeta Proyecto/)
   php -S 0.0.0.0:8080 -t .
   (0.0.0.0 para que el movil pueda conectarse; abrir el firewall
   del puerto 8080 si el movil no conecta)

4) EL BEACON DEL SENSOR (../arduino/)
   - Nombre del anuncio: Andreutale  (lo filtra EscannerBeaconBluetooth)
   - Codigo que emite en el minor: 1234
   - El beacon emite ~1 s cada ~4,5 s: al pulsar Escanear, esperar
     unos segundos.

5) PRUEBA COMPLETA
   Servidor arrancado -> placa emitiendo -> movil con Bluetooth ON,
   GPS ON y permisos concedidos -> Escanear -> "Codigo: 1234" ->
   Enviar -> "Enviado con exito" -> recargar la web -> "Codigo: 1234".
